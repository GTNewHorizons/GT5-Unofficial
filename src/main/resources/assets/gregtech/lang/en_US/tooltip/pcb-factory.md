Tier of the machine determines the available recipes
Each tier and upgrade requires additional structures
Power consumption is multiplied by {color_formula:Sqrt(structures)}
Tier 2 and 3 allow parallel by using extra nanites
Nanites have to be placed in a Nanite Containment Bus
The formula for parallels is the {color_formula:amount of nanites^{var:exponent}}, rounded up
Maximum parallel is {color_parallel:{var:max_parallel}}
Recipes require a cooling upgrade to be overclocked
Liquid Cooling uses {color_cold:{var:coolant} {L}/s} of {color_cold:distilled water} and enables default overclocks
Thermosink uses {aqua:{var:coolant} {L}/s} of {aqua:Super Coolant} and enables {light_purple:perfect overclocks}
Trace size can be changed to modify the material usage and machine speed
