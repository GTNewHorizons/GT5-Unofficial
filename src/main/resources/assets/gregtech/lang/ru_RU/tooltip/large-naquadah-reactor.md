Вырабатывает энергию из жидкого ядерного топлива или жидкого наквадахового топлива
Для работы требует {aqua:{var:liquid_air} {L}/с жидкого воздуха}, иначе {color_danger:топливо уничтожается}
{hr}
Можно подавать {blue:хладагент}, чтобы повысить {color_mechanic:эффективность}:
{blue:{var:coolant_amt_high} {L}/с} {blue:хладагента} : {color_mechanic:{var:coolant_ic2}%}
{blue:{var:coolant_amt_high} {L}/с} {blue:промышленного хладагента} : {color_mechanic:{var:coolant_super}%}
{blue:{var:coolant_amt_high} {L}/с} {blue:криотеума} : {color_mechanic:{var:coolant_cryo}%}
{blue:{var:coolant_amt_low} {L}/с} {blue:обогащённой тахионами времени жидкости} : {color_mechanic:{var:coolant_tachyon}%}
{hr}
Можно подавать {dark_aqua:усилитель}, чтобы повысить {color_mechanic:выходную мощность} и {color_mechanic:расход топлива}:
{dark_aqua:{var:excited_amt_high} {L}/с} {dark_aqua:расплавленного цезия} : {color_mechanic:{var:excited_caesium}x}
{dark_aqua:{var:excited_amt_high} {L}/с} {dark_aqua:расплавленного урана-235} : {color_mechanic:{var:excited_uranium}x}
{dark_aqua:{var:excited_amt_low} {L}/с} {dark_aqua:расплавленного наквадаха} : {color_mechanic:{var:excited_naquadah}x}
{dark_aqua:{var:excited_amt_low} {L}/с} {dark_aqua:расплавленного катализатора разделения атомов} : {color_mechanic:{var:excited_asc}x}
{dark_aqua:{var:excited_amt_low} {L}/с} {dark_aqua:пространственно расширенной жидкости} : {color_mechanic:{var:excited_space}x}
