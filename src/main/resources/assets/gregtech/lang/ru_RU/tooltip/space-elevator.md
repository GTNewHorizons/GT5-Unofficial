Может быть оснащёно до §a12 §7модулей космического лифта
Тир мотора ограничивает уровень модуля и количество возможных модулей
Каждый модуль имеет своё собственное пространство для ввода-вывода, за исключением энергии
Энергия поступает на этот контроллер и распределяется
Начиная с §dMK-III Моторов§7, структура может быть расширена до §a24 §7модулей
Макс. количество модулей составляет §a6§7/§912§7/§d15§7/§618§7/§c24§7 для моторов §aMK-I§7/§9MK-II§7/§dMK-III§7/§6MK-IV§7/§cMK-V§7 соответственно
Отключение этого контроллера также приостанавливает работу всех модулей
