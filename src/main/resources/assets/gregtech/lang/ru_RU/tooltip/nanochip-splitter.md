{dark_green:Правила} задаются по {color-pattern:red,yellow,green,aqua,light_purple:цвету} входа({dark_purple:ов}), {color-pattern:red,yellow,green,aqua,light_purple:цвету} выхода({dark_purple:ов}), поданному сигналу редстоуна и фильтрам предметов
{yellow:CC} будут переданы после выполнения всех условий {dark_green:правила}
