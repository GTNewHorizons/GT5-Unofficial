Для каждого рецепта требуется определённый {light_purple:катализатор}
{light_purple:Катализаторы} должны быть помещены в объёмное хранилище катализаторов

Тир {green:защитного ядра} определяет бонусы {green:фокусировки}
Поместите схему в контроллер, чтобы указать фокусированный выход, основываясь на порядке NEI
Если разделение входов включено: поместите схему в слот схемы люка
Потребляет {var:plasma} * {green:тир фокусировки} * sqrt({color_parallel:параллели}) {L} {blue:нептуниевой плазмы} для {green:фокусировки}
Чем выше {green:тир фокусировки}, тем {green:сильнее} эффект
{green:Сфокусированный} выход будет иметь {aqua:повышенную вероятность}, при этом другие выходы уменьшаются равномерно на общий прирост
Потребляет {var:plasma} * {green:тир фокусировки} * sqrt({color_parallel:параллели}) {L} {dark_green:фермиевой плазмы} для {dark_green:усиления всех выходов}
